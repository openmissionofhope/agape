# Security

Please report vulnerabilities privately through GitHub's "Report a vulnerability" (Security
advisories) on this repository, not in a public issue. Include steps to reproduce. Do not test
against the live site with real emergency submissions or by contacting real volunteers; run the
app locally (`npm run dev`) with `AGAPE_EMERGENCY_MODE=pilot`.

The security model is described in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#security-model).
